# API REST

A simple REST API built with Node.js and Express.

## Features

- CRUD operations
- Express
- JSON storage
- Layered architecture
- Error handling
- Request logging

## Installation

```bash
npm install
```

Run

```bash
npm start
```

Server

```
http://localhost:3000
```

Endpoints

- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id
